# Public release notes

## v0.4.0-public

First curated public research-software release of the Canadian Drill-Core Data Workflow.

### Included

- staged v0.1 → v0.4 methods and version history;
- detailed Mermaid workflow with v0.3.1–v0.3.5 and v0.4.1–v0.4.2;
- public source registry and compact project summary tables;
- synthetic interval, assay and regional-geochemistry examples;
- reusable Python modules for provenance, QC, harmonization, integration and grouped benchmarking;
- public demonstration notebooks;
- detailed v0.3 and v0.4 scientific syntheses;
- selected vector figures;
- automated tests and continuous-integration configuration.

### Scientific status

- v0.1.1: frozen source/provenance foundation.
- v0.2: RC2, PDF-complete with unresolved source limitations retained.
- v0.3: frozen regional/geochemical/downhole integration foundation.
- v0.4: frozen leakage-controlled whole-hole benchmark.

### Important limitations

The public repository does not redistribute original third-party assessment reports or large regional source packages. The supervised benchmark contains only four independent drill holes across two small tasks. Reported model scores are methodological benchmark results, not ore probabilities, prospectivity rankings or deployable exploration predictions.

### Next scientific step

Prioritize new independent drill-core information and/or new analytical modalities before any substantial benchmark tuning. Revised labels, features and eligibility rules should be frozen before new model fitting.
