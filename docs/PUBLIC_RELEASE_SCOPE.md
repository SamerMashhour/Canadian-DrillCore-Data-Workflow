# Public release scope

This repository is presented as an independent research project developed from public Canadian geoscience sources.

The public release is deliberately limited to:

- original project code and documentation;
- source registries and provenance metadata;
- compact derived summary tables;
- synthetic demonstration datasets;
- scientific workflow diagrams and vector figures;
- benchmark design, leakage controls and audit documentation.

Large third-party source packages and private archival build products are not redistributed here.

The repository does not claim affiliation with, endorsement by, or origin within any external research program. Its scientific focus is the workflow itself: source readiness, geological data integration, analytical harmonization, downhole context and grouped model validation.
